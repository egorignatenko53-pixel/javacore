# Java Core для AQA

Учебный репозиторий: изучаю Java с нуля с целью перейти в автоматизацию тестирования (AQA).
Здесь собираются задачи и упражнения по мере прохождения плана.

## Стек
- Java 21
- Maven
- IntelliJ IDEA
- Git / GitHub

## Прогресс

| Урок | Тема | Файлы | Статус |
|---|---|---|---|
| 1 | Первая программа, вывод в консоль | `Hi.java` | ✅ |
| 2 | Переменные, типы данных, арифметика, склейка строк | `Variables.java`, `Tasks.java` | ✅ |
| 3 | Условия: `if / else`, операторы сравнения, `&&`, `!` | `IfElse.java`, `HttpStatus.java` | 🔄 в процессе |

## Что уже умею
- Работать с типами `int`, `double`, `boolean`, `String`
- Использовать арифметику, целочисленное деление и остаток `%`
- Экранировать символы в строках (`\"`)
- Писать условия с `if / else if / else`
- Проверять код на граничных значениях

## План
1. Java Core: синтаксис, ООП, коллекции, исключения, Stream API
2. Юнит-тесты: JUnit 5, AssertJ
3. API-автотесты: REST Assured, Allure
4. UI-автотесты: Selenide, Page Object
5. CI: GitHub Actions
